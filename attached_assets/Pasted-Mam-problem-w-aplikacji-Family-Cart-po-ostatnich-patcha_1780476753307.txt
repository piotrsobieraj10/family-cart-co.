2. EDGE FUNCTION add-household-user
------------------------------------------------------------

Sprawdź i popraw:

supabase/functions/add-household-user/index.ts

Funkcja musi:
1. Obsługiwać CORS i OPTIONS.
2. Pobierać aktualnego użytkownika z JWT.
3. Nie ufać user_id z frontendu.
4. Sprawdzać household_id.
5. Sprawdzać, czy aktualny użytkownik jest członkiem domu.
6. Sprawdzać, czy ma rolę owner albo admin.
7. Obsługiwać nowy e-mail:
   - jeśli e-mail nie istnieje, wymagaj temporaryPassword min. 6 znaków,
   - utwórz konto auth przez Supabase Admin API,
   - ustaw profil:
     must_complete_profile = true,
     must_change_password = true,
   - dodaj użytkownika do household_members.
8. Obsługiwać istniejący e-mail:
   - nie twórz drugiego konta,
   - nie zmieniaj hasła,
   - dodaj użytkownika do household_members,
   - jeśli już jest członkiem tego domu, zwróć czytelny komunikat.
9. Zwracać zawsze JSON:
   { ok: true, message: "...", ... }
   albo
   { ok: false, code: "...", error: "..." }

Obsłuż błędy:
- MISSING_HOUSEHOLD_ID
- MISSING_EMAIL
- INVALID_ROLE
- NOT_AUTHENTICATED
- EMAIL_NOT_CONFIRMED
- NOT_HOUSEHOLD_MEMBER
- NOT_ALLOWED
- TEMP_PASSWORD_REQUIRED
- USER_ALREADY_MEMBER
- SUPABASE_ADMIN_CONFIG_MISSING
- AUTH_CREATE_USER_FAILED
- PROFILE_UPSERT_FAILED
- MEMBER_INSERT_FAILED
- UNKNOWN_ERROR
